# .NET, Blazor og Azure SQL

Viderefører beslutningene fra 2026-06-18: .NET/ASP.NET Core, Blazor Interactive Server,
EF Core og Azure SQL på Linux App Service. Domain holder rene modeller og beregninger,
Application definerer tjenestegrenser, Infrastructure skjuler adaptere og Web eier grensesnittet.
Dette gir én C#-stakk og gjenbruk av serverlogikk. Matt Pocock-metoden endrer arbeidsflyten,
og gir ingen grunn i seg selv til å bytte plattform. Kilde: den arkiverte beslutningsloggen.

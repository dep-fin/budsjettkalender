# Små vertikale endringer med separate kilder til kontekst

På brukerens bestilling 2026-10-20 tilpasses arbeidsmåten til dep-fin/Matt-Pocock.
GitHub Issues bærer oppgaver/spesifikasjoner, GLOSSARY.md bærer domenespråk og ADR-er bærer
varige avveininger. AGENTS.md er den felles indeksen; CLAUDE.md importerer den.

Det tidligere kravet om å lese hele øktloggen og arbeide fasevis erstattes av
behovsstyrte pekere, avgrensede oppgaver, atferdstester og todelt endringsgjennomgang.
Den gamle loggen arkiveres for sporbarhet. Eksisterende faseplaner beholdes som historikk.
Dette reduserer motstridende kontekst uten å miste begrunnelsene for tidligere valg.

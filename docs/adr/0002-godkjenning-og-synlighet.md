# Godkjenning før publisering og synlighet på server

Viderefører beslutningene fra 2026-06-18/19: automatiske og genererte frister går via forslag
og aktiv administratorgodkjenning. Synlighetsfilteret påføres før projeksjon/retur for å unngå
at skjulte frister sendes til klienten. POL velges eksplisitt, og endringsforslag endrer aldri
synlighet. Løp identifiserer funksjonen uavhengig av rundskrivnummer; kilder kan derfor byttes
bak IKilde uten å endre publiseringsregelen.

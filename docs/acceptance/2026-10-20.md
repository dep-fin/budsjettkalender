## Miljø og utfall

Windows, SDK 10.0.402, Playwright 1.63.0 og Edge 155.0.4283.62, headless.
Kestrel kjørte Development + Demo=true på loopback. Hvert scenario opprettet en ny
SQLite-fil, standard demo-personaer og egne syntetiske data. Tidligere demodatoer ble
lest med historikk; nye frister bruker 2030, genereringen stortingsvalgåret 2033.
Ingen produksjonsdata, Entra-innlogging, eksterne skriveroperasjoner eller språkmodell.

**12 nettleserscenarioer og 447 ordinære tester bestått, begge med 0 feil og 0 hopp.**
Ordinær suite består av 442 tidligere + 2 demo-/HTTP-tilfeller + 3 ansvarstilfeller.
Låst restore og Release-bygg av løsning og nettleserprosjekt passerer. SQL-prosjektets
låste restore, Release-bygg og oppdagelse av 22 tilfeller passerer; SQL Server er ikke
kjørt lokalt. Alle tre kandidatjobber i CI skal være grønne før merge.

Lokal evidens: `browser-final.trx`, `ordinary.trx`, røde/grønne regresjonskjøringer,
kalenderskjermbilde, Word-/ICS-/JSON-nedlastinger og app-logger i mappen valgt med
AARSHJUL_BROWSER_EVIDENCE, utenfor repoet. CI laster bare opp TRX. Feed-token/URL-er
og rå nettleserspor publiseres ikke. Kommandoer står i
[utviklingsoppsettet](../development.md#obligatorisk-nettleserakseptanse).

## Rød → grønn

- Demo-utlogging i Development + Demo=true pekte til umappet MicrosoftIdentity-rute;
  nettleserprøven viste Not Found. Layouten leser nå samme demoflagg som oppstarten og
  bruker full navigasjon ved utlogging. Begge demomiljøer har HTTP-regresjon.
  Konsollkontrollen fanget også favicon-404; app og demoside angir nå et tomt dataikon.
- Generering i stortingsvalgår kastet KeyNotFoundException ved rendering av tentativt
  anker. Den røde UI-prøven brøt kretsen. Lasting oppretter nå tomme ankerverdier og
  bevarer satte datoer. Samme prøve er grønn gjennom regenerering og godkjenning.
- Ansvarstildeling på eksisterende gjøremål ga DbUpdateConcurrencyException og brutt
  krets. Tre Application-regresjoner gjenskapte feilen ved gjøremåls-/regelredigering og
  deretter oppdaterende synk. Nye barn med ferdig Guid var blitt behandlet som oppdateringer.
  De registreres nå som innsettinger; én atomisk SaveChanges beholdes. Alle tre og UI-flyten er grønne.

[Siste CI for PR #35](https://github.com/depmartin/Budsjettkalender/actions/runs/39443717020)
bekreftet faktisk 442 ordinære og 22 SQL Server-tester, begge med 0 feil/hopp.
Dette er forgjengerbevis, ikke SQL-bevis for kandidaten. Ingen SQL-test er erstattet
med SQLite eller hoppet over i obligatorisk CI.

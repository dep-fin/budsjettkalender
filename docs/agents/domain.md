# Domain docs

Repoet bruker én kontekst: rotens `GLOSSARY.md` og `docs/adr/`.

Les begrepslisten før domeneanalyse, oppgaveskriving og valg av testnavn. Les ADR-er som
berører modulen før utforming eller endring. Bruk samme begrep i kode, tester og oppgaver.
Ved konflikt med en eksisterende beslutning: beskriv konflikten og begrunnelsen for å
endre den før implementering.

Legg til begreper når betydningen er avklart. Opprett en kort ADR når en reell,
varig avveining ellers ville være vanskelig å forstå. Oppdater beslutningen som endres;
en øktlogg er historikk, ikke en ny kilde til gjeldende regler.

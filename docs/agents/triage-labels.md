# Triage labels

| Rolle | GitHub-etikett | Betydning |
| --- | --- | --- |
| needs-triage | needs-triage | Må vurderes |
| needs-info | needs-info | Mangler en avklaring |
| ready-for-agent | ready-for-agent | Avgrenset, testbar og uten åpne blokkeringer |
| ready-for-human | ready-for-human | Krever menneskelig handling |
| wontfix | wontfix | Skal ikke gjennomføres |

Behold denne ordlisten ved bruk av `triage`. Opprett manglende etiketter ved første bruk.

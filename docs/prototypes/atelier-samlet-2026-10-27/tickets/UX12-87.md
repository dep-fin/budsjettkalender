# UX12: Atelier: maleksport og forhåndsvist import uten kontrakttap

Blocked by: #86

Hovedoppgave: #75
Plan-ID: UX12. Avgrenset leveranse, men ikke startklar før Blocked by er lukket.
Dekker historier i #75: 83.

## Problem Statement

Et enklere malgrensesnitt må bevare tidligere eksport/import og gjøre erstatt-alt-konsekvensen forståelig.

## Solution

Lever Overfør mal i Årsmal med eksisterende versjonerte format, tydelig forhåndsvisning og kontrollert importbekreftelse.

### Akseptansekriterier

- [ ] Eksport/import roundtrip bevarer alle støttede felter og beregningsresultater.
- [ ] Eldre filer uten tittel og gyldige tidligere parametre støttes som før.
- [ ] Blandet import viser hva som tas inn/utelates og hvor mange eksisterende regler som erstattes.
- [ ] Null gyldige regler har eksplisitt tømmingskonsekvens og krever bekreftelse.
- [ ] Ugyldig versjon, null-liste/-rad og duplikat-ID avviser hele filen uten mutasjon.
- [ ] Avbryt og lagringsfeil bevarer gammel mal; vellykket import vises i liste/regelbygger og brukes i generering.
- [ ] Eksport/deling kan ha kontekstuell lenke hit uten separat mal-kopi.

## User Stories

1. Som administrator vil jeg laste ned alle malregler med identitet og parametre, slik at de kan gjenopprettes.
2. Som administrator vil jeg åpne eldre malfiler, slik at dagens kompatibilitet beholdes.
3. Som administrator vil jeg se gyldige/utelatte regler før bekreftelse, slik at konsekvensen er kjent.
4. Som administrator vil jeg se tydelig at null gyldige regler tømmer malen, slik at erstatt-alt ikke overrasker.
5. Som administrator vil jeg avbryte uten mutasjon og få atomisk import, slik at eksisterende mal bevares ved feil.
6. Som administrator vil jeg generere fra importert mal, slik at overføring bruker det samme regelsettet.

## Implementation Decisions

- Gjenbruk IMalDatautveksling og Regelparser; bevar formatversjon, ID, løp, tittel, kategori, regeltype, parametre og valgårsvalg.
- Ugyldig regel utelates med advarsel. Filfeil avviser hele importen; gyldig delmengde erstatter hele malen, også når tom.
- Behold eldre tom tittel og øvrige kompatibilitetsvalg i ADR-0008; UI-forhåndsvisning overstyrer ikke servervalidering.
- Fasemal er egen konfigurasjon og føyes ikke stille inn i gammelt gjentaksregelformat.

## Testing Decisions

- Viderefører avklart testgrense fra #75: eksisterende reelle nettlesertester mot Kestrel/Blazor er hovedgrensen, med dagens tjenestekontrakter for roller, synlighet og publisering. Test ekstern atferd og lagret resultat, ikke privat tilstand eller CSS.
- Eksisterende IMalDatautveksling-/rollback-tester er tjenestegrensen; suppleres med ekte UI-filvalg, forhåndsvisning, avbryt og bekreftelse.
- Test innhold og etterfølgende atferd, ikke private serialiseringshjelpere.
- Før ferdigstilling: relevante regresjoner, Standards-/Spec-review, nødvendig sikkerhetsaudit og grønne ordinære/SQL Server-/nettleserjobber etter prosjektets regler. Lokal demo erstatter ikke Azure/Entra/Outlook-bevis.

## Out of Scope

- Nytt importformat eller endring av erstatt-alt-semantikk.
- Generell frist-/databaseimport og fasemaleksport.
- Automatisk publisering, stille POL-valg, endret synlighet ved endringsforslag eller uautorisert produksjonsutrulling.
